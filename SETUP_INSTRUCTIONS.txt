                    📱 CHATNOTES - SETUP INSTRUCTIONS
                      WhatsApp-like Chat & Notes App

Welcome! This guide will help you get the app running in minutes.

🎯 PREREQUISITES
================================================================================
Make sure you have these installed:
  ✓ Node.js v16+ (download from nodejs.org)
  ✓ npm (comes with Node.js)

Verify installation by opening Command Prompt and typing:
  node --version
  npm --version

🚀 INSTALLATION STEPS
================================================================================

STEP 1: Navigate to Project Folder
-----------
Press Win+R, type:
  cmd
Hit Enter

Then type (adjust path if different):
  cd "c:\Users\folio\Desktop\live chate"

STEP 2: Install All Dependencies
-----------
Type this command and wait for it to complete (first time takes ~2-5 minutes):
  npm install-all

This installs dependencies for:
  • Frontend (React + Vite)
  • Backend (Node.js + Express)
  • Root project

STEP 3: Start the Application
-----------
Type:
  npm run dev

You should see output like:
  ✔ VITE v5.0.8  ready in 123 ms
  ➜  Local:   http://localhost:3000
  
  ✅ Server running on http://localhost:5000

🌐 OPENING THE APP
================================================================================
1. Open your web browser
2. Go to: http://localhost:3000
3. Enter your name (any username)
4. Click "Start Chat"

That's it! You're ready to use the app.

🐛 TROUBLESHOOTING
================================================================================

Problem: "npm: command not found"
Solution: Install Node.js from nodejs.org

Problem: "Port 3000 already in use"
Solution: Another app is using it. Either:
  a) Close the other app
  b) Or edit frontend/vite.config.js and change port 3000 to 3001

Problem: "Port 5000 already in use"
Solution: Either:
  a) Close the other app
  b) Or edit backend/.env and change PORT=5000 to PORT=5001

Problem: App not loading
Solution:
  1. Check both terminal windows show "ready" messages
  2. Try refreshing browser (Ctrl+R)
  3. Check console for errors (F12)

Problem: Npm install failed
Solution:
  1. Delete folder: frontend/node_modules
  2. Delete folder: backend/node_modules
  3. Delete file: package-lock.json
  4. Run: npm install-all again
